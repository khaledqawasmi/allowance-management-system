Allowance Management System

A backend system for managing personal allowance, tracking spending, calculating available budgets, and suggesting suitable places based on the available budget.


Features

* Manage daily, weekly, monthly, yearly, and custom allowances.
* Calculate daily budgets and remaining balances.
* Record and track spending.
* Suggest suitable places based on budget.

Technologies

* Python
* Flask REST API
* PostgreSQL
* Swagger / Postman
